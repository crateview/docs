## کنفیگریشن پرتیں۔

ایپلیکیشن ڈیفالٹس کی تعریف `nuxt.config.ts` اور `app/app.config.ts` میں کی گئی ہے۔ جب سرور شروع ہوتا ہے تو ماحولیاتی متغیرات رن ٹائم ڈیفالٹس کو اوور رائیڈ کر دیتے ہیں۔ ڈویلپمنٹ اور بلڈ کمانڈز `.env` پڑھیں۔ پروڈکشن نوڈ انٹری پوائنٹ اسے خود بخود نہیں پڑھتا ہے۔

رن ٹائم ماحول کے متغیرات کو تبدیل کرنے کے بعد سرور کو دوبارہ شروع کریں۔ ماخذ کی سطح کے اجزاء کی ترتیب میں ترمیم کے لیے ایک نئی پروڈکشن کی تعمیر کی ضرورت ہے۔

## رجسٹری اور سیشن کی ترتیبات

| متغیر | طے شدہ | مقصد |
| ------------------------------ | ----------------------- | ----------------------------------- |
| `NUXT_REGISTRY_UPSTREAM` | `http://127.0.0.1:5000` | سرور سائیڈ رجسٹری کی اصل۔ |
| `NUXT_REGISTRY_DELETE_ENABLED` | `false` | UI میں مینی فیسٹ ڈیلیٹ کو ظاہر کریں۔ |
| `NUXT_SESSION_PASSWORD` | بے ترتیب فی عمل | خفیہ UI سیشنز کو خفیہ کرنے کے لیے استعمال کیا جاتا ہے۔ |
| `HOST` | رن ٹائم پر منحصر ہے۔ | نوڈ سرور سننے والا انٹرفیس۔ |
| `PORT` | `3000` | نوڈ سرور سننے والا بندرگاہ۔ |

اپ اسٹریم ایک HTTP(S) اصل ہونا چاہیے جو فرنٹ اینڈ سرور سے قابل رسائی ہو۔ اسناد کو URL سے باہر رکھیں۔ درخواستیں موجودہ صارف کی توثیق کا استعمال کرتی ہیں۔ Crateview رجسٹری رسائی کنٹرول کو تبدیل نہیں کرتا ہے۔

## عوامی برانڈنگ متغیرات

ذیل کے تمام نام `NUXT_PUBLIC_BRAND_` سابقہ ​​استعمال کرتے ہیں:

| لاحقہ | مقصد |
| ------------------------------------------- | ----------------------------------------------- |
| `NAME` | درخواست کا نام۔ |
| `DESCRIPTION` | درخواست کی تفصیل۔ |
| `LOGO_LIGHT`، `LOGO_DARK` | لوگو پاتھ یا HTTP(S) URLs۔ |
| `FAVICON` | براؤزر آئیکن پاتھ یا یو آر ایل۔ |
| `TITLE_TEMPLATE` | صفحہ کا عنوان؛ `%s` کو صفحہ کے عنوان سے بدل دیا گیا ہے۔ |
| `PRODUCT_URL`, `DOCS_URL`, `REPOSITORY_URL` | اختیاری نیویگیشن لنکس۔ |

عوامی ترتیب براؤزر کو بھیجی جاتی ہے۔ `NUXT_PUBLIC_*` متغیرات میں پاس ورڈز یا ٹوکن کبھی بھی اسٹور نہ کریں۔ رنگ اور نوع ٹائپ کے اختیارات کے لیے [برانڈنگ اور تھیمنگ](/ur/docs/v0.5/theming) دیکھیں۔

## نیٹ ورک لے آؤٹ

براؤزر ایک اصل پر Crateview کے ساتھ بات چیت کرتا ہے۔ Nitro رجسٹری کلائنٹس کے لیے `/v2/**` پراکسیز کرتا ہے اور `/api/registry/**` کے ذریعے رجسٹری میٹا ڈیٹا پڑھتا ہے۔ یہ خود رجسٹری تک کراس اوریجن براؤزر تک رسائی کی ضرورت سے گریز کرتا ہے۔

ریورس پراکسی کے پیچھے، عوامی اصل اور پروٹوکول ہیڈر کو محفوظ رکھیں۔ عوامی فرنٹ اینڈ ایڈریس بھی رجسٹری ایڈریس ہے جو کاپی شدہ pull کمانڈز میں ظاہر ہوتا ہے۔ دور دراز سے تصدیق شدہ استعمال کے لیے، براؤزر یا CLI اسناد کو قبول کرنے سے پہلے HTTPS کو درست طریقے سے ختم کریں۔

## Compose بمقابلہ اسٹینڈ اسٹون کنفیگریشن

بنڈل شدہ Compose فائل جان بوجھ کر `NUXT_REGISTRY_UPSTREAM=http://registry:5000` کے ساتھ اپنی `registry` سروس سے منسلک ہوتی ہے۔ کنٹینر کی تعیناتی میں دوسری رجسٹری استعمال کرنے کے لیے، اس سروس ماحول کو اپنائیں یا فرنٹ اینڈ کو الگ سے چلائیں۔ یہ نہ سمجھیں کہ میزبان لوپ بیک رجسٹری کنٹینر گیٹ وے کے ذریعے قابل رسائی ہے۔
## اس ورژن کی ترتیب

نگرانی اختیاری، بطور طے شدہ بند ہے۔ فعال ہونے پر جائزہ ڈیش بورڈ کھولتا ہے؛ ورنہ /home سے /explore جاتا ہے۔ فعال کرنے سے عوامی رجسٹری کے گمنام زائرین سمیت ہر UI صارف کو پوری رجسٹری کا عملی ڈیٹا ملتا ہے۔ منظم ٹوکن موڈ کو عالمی پڑھنے کی اجازت بھی چاہیے۔
