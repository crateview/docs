## আপনার রেজিস্ট্রি একটি পরিষ্কার দৃশ্য

Crateview হল Docker এবং OCI কন্টেইনার রেজিস্ট্রির জন্য একটি ওয়েব ইন্টারফেস। এটি আপনাকে সংগ্রহস্থল এবং ট্যাগগুলি খুঁজে পেতে, মাল্টি-প্ল্যাটফর্ম চিত্রগুলি পরিদর্শন করতে, ম্যানিফেস্ট এবং কনফিগার নথিগুলি পড়তে এবং সংকুচিত স্তরগুলি এবং তাদের ইতিহাস বুঝতে সহায়তা করে৷

এটি আপনার রেজিস্ট্রির পাশাপাশি চলে। রেজিস্ট্রি ছবি সঞ্চয় করে এবং অ্যাক্সেস নিয়ন্ত্রণ প্রয়োগ করে; Crateview ইন্টারফেস এবং একই-অরিজিন প্রক্সি সরবরাহ করে। Docker এবং অন্যান্য OCI ক্লায়েন্টরা তাদের রেজিস্ট্রি ঠিকানা হিসাবে ফ্রন্টএন্ড অরিজিন ব্যবহার করতে পারে।

## স্থাপত্য

```text
Browser / Docker / Podman / ORAS
              |
       Crateview (Nuxt / Nitro)
              |
   Your existing OCI registry
```

ফ্রন্টএন্ড স্ট্যান্ডার্ড রেজিস্ট্রি HTTP API V2 পড়ে। UI মেটাডেটা ক্যাটালগ, ট্যাগ তালিকা, ম্যানিফেস্ট এবং ইমেজ কনফিগারেশন ব্লব থেকে প্রাপ্ত। এটি একটি পৃথক অনুসন্ধান সূচক বা অ্যাপ্লিকেশন ডাটাবেস প্রয়োজন নেই.

## সমর্থিত বৈশিষ্ট্য

- সংগ্রহস্থল-নাম অনুসন্ধান, ট্যাগ পরামর্শ এবং নেস্টেড নেমস্পেস।
- ট্যাগ টেবিল, প্ল্যাটফর্ম নির্বাচন, সংকুচিত স্তর আকার এবং চিত্র ইতিহাস।
- বর্ণনা, উৎস URL, ডকুমেন্টেশন এবং লাইসেন্সের জন্য OCI টীকা।
- ক্লিপবোর্ড সমর্থন সহ কাঁচা ম্যানিফেস্ট এবং কনফিগার JSON।
- OCI রেফারার, OCI ক্লায়েন্টদের দ্বারা রক্ষণাবেক্ষণ করা স্ট্যান্ডার্ড digest-ট্যাগ সূচক ফলব্যাক সহ।
- বেনামী অ্যাক্সেস এবং নেটিভ htpasswd Basic Auth।
- ঐচ্ছিক ম্যানিফেস্ট মুছে ফেলা, প্রভাবিত ট্যাগগুলি নিশ্চিতকরণের আগে দেখানো হয়েছে।
- দুটি ইন্টারফেস ভাষা (ইংরেজি ও জার্মান), সিস্টেম/হালকা/গাঢ় ও পরিবর্তনযোগ্য ব্র্যান্ডিং।


## সীমানা জানুন

স্ট্যান্ডার্ড API push টাইমস্ট্যাম্প, ডাউনলোড পরিসংখ্যান, পছন্দ বা দুর্বলতা স্ক্যানিং প্রদান করে না। Crateview এই মানগুলি তৈরি করে না। একটি ছবি তৈরির তারিখ ইমেজ মেটাডেটা থেকে আসে এবং এটি আপলোডের সময় নয়। প্রদর্শিত আকারগুলি সংকুচিত চিত্র স্তরগুলি বর্ণনা করে, রেজিস্ট্রির ডিস্ক ব্যবহার নয়।

বাহ্যিক Bearer-টোকেন পরিষেবা, OIDC, ব্যবহারকারী প্রশাসন এবং API-কী ব্যবস্থাপনা সমন্বিত নয়। স্বাক্ষর শিল্পকর্ম রেফারার হিসাবে তালিকাভুক্ত করা যেতে পারে; এটি ক্রিপ্টোগ্রাফিক স্বাক্ষর যাচাইকরণ নয়।

[installation](/bn/docs/v0.1/installation) দিয়ে শুরু করুন, তারপর [configuration](/bn/docs/v0.1/configuration) এবং [authentication](/bn/docs/v0.1/authentication) পর্যালোচনা করুন।
