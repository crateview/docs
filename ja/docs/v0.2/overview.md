## レジストリをより明確に表示

Crateview は、Docker および OCI コンテナー レジストリ用の Web インターフェイスです。これは、リポジトリとタグの検索、マルチプラットフォーム イメージの検査、マニフェストと構成ドキュメントの読み取り、圧縮レイヤーとその履歴の理解に役立ちます。

レジストリと並行して実行されます。レジストリはイメージを保存し、アクセス制御を強制します。 Crateview は、インターフェイスと同一生成元プロキシを提供します。 Docker およびその他の OCI クライアントは、フロントエンドのオリジンをレジストリ アドレスとして使用できます。

![Alpine およびネストされたデモ リポジトリを含む Crateview リポジトリの概要。](https://crateview.de/images/docs/v0.2/repositories-light.webp)

## 建築

```text
Browser / Docker / Podman / ORAS
              |
       Crateview (Nuxt / Nitro)
              |
   Your existing OCI registry
```

フロントエンドは、標準レジストリ HTTP API V2 を読み取ります。 UI メタデータは、カタログ、タグ リスト、マニフェスト、およびイメージ構成 BLOB から派生します。別の検索インデックスやアプリケーション データベースは必要ありません。

## サポートされている機能

- リポジトリ名の検索、タグの提案、およびネストされた名前空間。
- タグテーブル、プラットフォームの選択、圧縮レイヤーサイズ、画像履歴。
- 説明、ソース URL、ドキュメント、ライセンスの OCI 注釈。
- クリップボードをサポートする生のマニフェストと構成 JSON。
- OCI リファラー (OCI クライアントによって維持される標準の digest タグ インデックス フォールバックを含む)。
- 匿名アクセスとネイティブ htpasswd Basic Auth。
- オプションのマニフェストの削除。影響を受けるタグは確認前に表示されます。
- 英語とドイツ語の2言語、システム/ライト/ダーク、変更可能なブランド設定。


## 境界を知る

標準の API は、push タイムスタンプ、ダウンロード統計、お気に入り、または脆弱性スキャンを提供しません。 Crateview はこれらの値を捏造しません。画像の作成日は画像のメタデータから取得され、アップロード時刻ではありません。表示されるサイズは、レジストリのディスク使用量ではなく、圧縮されたイメージ レイヤーを表します。

外部の Bearer トークン サービス、OIDC、ユーザー管理、および API キー管理は統合されていません。署名アーティファクトはリファラーとしてリストされる場合があります。これは暗号署名の検証ではありません。

[インストール](/ja/docs/v0.2/installation)]から始めて、[構成](/ja/docs/v0.2/configuration)と[認証](/ja/docs/v0.2/authentication)]を確認してください。
