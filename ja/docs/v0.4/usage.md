## リポジトリとタグを検索する

探索にはリポジトリが表示されます。検索は名前と repository:tag に対応します。リポジトリを開くとタグを確認できます。

標準はテーブル表示で、グリッドに切り替えられます。スラッシュ付きの名前は名前空間になります。サイドバーは幅変更と折りたたみができ、状態はローカル保存されます。検索はサイドバーにあります。

/ または Ctrl+K（macOS は Cmd+K）で検索・移動のコマンドパレットが開きます。名前空間フォルダは折りたためます。設定には言語、システム/ライト/ダークと、依存ライセンスや原文の通知を検索できる情報画面があります。

![ブランディングとテーマ設定](https://crateview.de/images/docs/v0.4/settings-light.webp)

## 画像を検査する

リポジトリを開いてタグを選択します。イメージ ビューには、digest、利用可能なプラットフォーム、圧縮レイヤー サイズ、作成メタデータが表示されます。

マルチプラットフォーム イメージの場合は、プラットフォーム セレクターでオペレーティング システムとアーキテクチャを選択します。レイヤー履歴と選択した画像構成は、その選択に従います。 [生のマニフェスト] タブには、イメージのルート マニフェストまたはインデックスが表示されます。 [構成] には、選択したプラットフォームの構成が表示されます。

![プラットフォームの選択、レイヤー履歴、および pull コマンドを含むアルパイン イメージの詳細。](https://crateview.de/images/docs/v0.4/image-light.webp)

## Pull コマンド

コマンド パネルには、イメージ用の Docker、Podman、および Skopeo コマンドと、アーティファクト用の ORAS/Podman アーティファクト コマンドが提供されます。コマンドをコピーし、自分のターミナルで実行します。

```sh
docker pull registry.example.com/team/service:latest
podman pull registry.example.com/team/service:latest
oras pull registry.example.com/team/report:latest
```

サンプル ホストをパブリック Crateview オリジンに置き換えます。 CLI 認証はブラウザ セッションとは別のものです。

## OCI メタデータとリファラー

説明、ライセンス、およびソース リンクは、利用可能な場合、OCI 注釈またはイメージ構成ラベルから読み取られます。欠落しているメタデータは推測されず、空のままになります。

「リファラー」タブには、OCI リファラー API が表示されます。レジストリがそのエンドポイントを実装していない場合、Crateview は、OCI クライアントによって維持される標準の digest 派生タグ インデックスを読み取ります。すべてのマニフェストをスキャンして独自のインデックスを構築するわけではありません。リストされた署名アーティファクトは、自動的に検証されず、信頼済みとしてマークされることもありません。

## タイムスタンプとサイズを解釈する

イメージの作成時間は、イメージ構成またはアノテーションによって提供されます。タグがいつこのレジストリにプッシュされたかはわかりません。レイヤーは共有される可能性があり、削除されたデータはガベージ コレクションまで残る可能性があるため、圧縮レイヤー サイズではディスク消費量は測定されません。
