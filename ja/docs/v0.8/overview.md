## レジストリをより明確に表示

Crateview は、Docker および OCI コンテナー レジストリ用の Web インターフェイスです。これは、リポジトリとタグの検索、マルチプラットフォーム イメージの検査、マニフェストと構成ドキュメントの読み取り、圧縮レイヤーとその履歴の理解に役立ちます。

レジストリと並行して実行されます。レジストリはイメージを保存し、アクセス制御を強制します。 Crateview は、インターフェイスと同一生成元プロキシを提供します。 Docker およびその他の OCI クライアントは、フロントエンドのオリジンをレジストリ アドレスとして使用できます。

![Alpine およびネストされたデモ リポジトリを含む Crateview リポジトリの概要。](https://crateview.de/images/docs/v0.8/repositories-light.webp)

## 建築

```text
Browser / Docker / Podman / ORAS
              |
       Crateview (Nuxt / Nitro)
              |
   Your existing OCI registry
```

カタログにDBは不要です。任意の監視は永続SQLiteを使用します。アカウントは htpasswd と別の権限ファイルを使用します。

## サポートされている機能

- リポジトリ名の検索、タグの提案、およびネストされた名前空間。
- タグテーブル、プラットフォームの選択、圧縮レイヤーサイズ、画像履歴。
- 説明、ソース URL、ドキュメント、ライセンスの OCI 注釈。
- クリップボードをサポートする生のマニフェストと構成 JSON。
- OCI リファラー (OCI クライアントによって維持される標準の digest タグ インデックス フォールバックを含む)。
- 匿名アクセスとネイティブ htpasswd Basic Auth。
- オプションのマニフェストの削除。影響を受けるタグは確認前に表示されます。
- 13 のインターフェイス言語、システム/ライト/ダーク、および設定可能なブランディング。

- 監視は任意で初期状態は無効です。有効時は概要がダッシュボードを開き、無効時は /home が /explore に転送されます。有効化すると公開レジストリの匿名訪問者を含む全UI利用者にレジストリ全体の運用情報が公開されます。管理トークンモードでは全体の読み取り権限も必要です。

## 境界を知る

標準の API は、push タイムスタンプ、ダウンロード統計、お気に入り、または脆弱性スキャンを提供しません。 Crateview はこれらの値を捏造しません。画像の作成日は画像のメタデータから取得され、アップロード時刻ではありません。表示されるサイズは、レジストリのディスク使用量ではなく、圧縮されたイメージ レイヤーを表します。

管理には設定とユーザーがあります。アカウントメニューでも言語とテーマを選べます。アカウントでは現在のパスワードを確認して自分のパスワードを変更します。ユーザー一覧と作成はサーバー許可リストで制御され、トークン権限は読み取り専用です。新しいパスワードは12文字以上72 UTF-8バイト以下です。新しいトークンアカウントには最初リポジトリ権限がありません。

サーバーの許可リストがアカウントの一覧表示、作成、パスワードリセット、削除を制御します。 右端の三点メニューから、管理者は他のユーザーのパスワードを古いパスワードなしでリセットしたり、確認後にアカウントを削除したりできます。リセットではリポジトリ権限を保持し、削除では権限も削除します。自分のメニューは「アカウント」を開き、現在のパスワードで変更を確認します。自分のアカウントは削除できません。

[インストール](/ja/docs/v0.8/installation)]から始めて、[構成](/ja/docs/v0.8/configuration)と[認証](/ja/docs/v0.8/authentication)]を確認してください。

## アプリとしてインストール（PWA）

インストール可能なアプリ。翻訳済みのオフライン起動メッセージ、再試行、カスタムアイコンを提供します。レジストリ閲覧とアカウント操作にはネットワークが必要です。
