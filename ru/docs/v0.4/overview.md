## Более четкое представление вашего реестра

Crateview — это веб-интерфейс для реестров контейнеров Docker и OCI. Он помогает вам находить репозитории и теги, проверять многоплатформенные изображения, читать манифесты и документы конфигурации, а также понимать сжатые слои и их историю.

Он работает вместе с вашим реестром. В реестре хранятся изображения и обеспечивается контроль доступа; Crateview предоставляет интерфейс и прокси того же происхождения. Docker и другие клиенты OCI могут использовать источник внешнего интерфейса в качестве адреса реестра.

![Обзор репозитория Crateview с Alpine и вложенными демонстрационными репозиториями.](https://crateview.de/images/docs/v0.4/repositories-light.webp)

## Архитектура

```text
Browser / Docker / Podman / ORAS
              |
       Crateview (Nuxt / Nitro)
              |
   Your existing OCI registry
```

Каталог не требует БД; необязательный мониторинг использует постоянную SQLite.

## Поддерживаемые функции

- Поиск по имени репозитория, предложения тегов и вложенные пространства имен.
- Таблицы тегов, выбор платформы, размеры сжатых слоев и история изображений.
- OCI аннотации к описаниям, исходным URL-адресам, документации и лицензиям.
- Необработанный манифест и конфигурация JSON с поддержкой буфера обмена.
- Рефереры OCI, включая стандартный резервный индекс индекса digest, поддерживаемый клиентами OCI.
- Анонимный доступ и родной htpasswd Basic Auth.
- Необязательное удаление манифеста с отображением затронутых тегов перед подтверждением.
- Два языка интерфейса (английский и немецкий), Система/Светлая/Тёмная и настраиваемое оформление.


- Мониторинг необязателен и изначально выключен. При включении Обзор открывает панель, иначе /home перенаправляет на /explore. Включение раскрывает общие эксплуатационные данные всем пользователям UI, включая анонимных посетителей публичных реестров.

## Знайте границы

Стандартный API не предоставляет временные метки push, статистику загрузок, избранное или сканирование уязвимостей. Crateview не выдумывает эти значения. Дата создания изображения берется из метаданных изображения и не является временем его загрузки. Отображаемые размеры описывают слои сжатого образа, а не использование диска реестра.

Службы внешних токенов Bearer, OIDC, администрирования пользователей и управления ключами API не интегрированы. Артефакты подписи могут быть указаны как рефереры; это не проверка криптографической подписи.

Начните с [installation](/ru/docs/v0.4/installation), затем просмотрите [configuration](/ru/docs/v0.4/configuration) и [authentication](/ru/docs/v0.4/authentication).
