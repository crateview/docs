## Слои конфигурации

Настройки приложения по умолчанию определены в `nuxt.config.ts` и `app/app.config.ts`. Переменные среды переопределяют значения по умолчанию во время выполнения при запуске сервера. Команды разработки и сборки читают `.env`; точка входа производственного узла не считывает его автоматически.

Перезапустите сервер после изменения переменных среды выполнения. Для редактирования конфигурации компонента на уровне исходного кода требуется новая производственная сборка.

## Настройки реестра и сеанса

| Переменная | По умолчанию | Цель |
| ------------------------------ | ----------------------- | ----------------------------------- |
| `NUXT_REGISTRY_UPSTREAM` | `http://127.0.0.1:5000` | Источник реестра на стороне сервера. |
| `NUXT_REGISTRY_DELETE_ENABLED` | `false` | Предоставьте возможность удаления манифеста в пользовательском интерфейсе. |
| `NUXT_SESSION_PASSWORD` | Случайно для каждого процесса | Секрет, используемый для шифрования сеансов пользовательского интерфейса. |
| `HOST` | Зависит от времени выполнения | Интерфейс прослушивания Node-сервера. |
| `PORT` | `3000` | Порт прослушивания сервера узла. |

Восходящий поток должен быть источником HTTP(S), доступным с внешнего сервера. Не допускайте попадания учетных данных в URL-адрес. Запросы используют аутентификацию текущего пользователя; Crateview не заменяет контроль доступа к реестру.

## Переменные публичного брендинга

Все имена ниже используют префикс `NUXT_PUBLIC_BRAND_`:

| Суффикс | Цель |
| ------------------------------------------- | ----------------------------------------------- |
| `NAME` | Имя приложения. |
| `DESCRIPTION` | Описание приложения. |
| `LOGO_LIGHT`, `LOGO_DARK` | Пути к логотипам или URL-адреса HTTP(S). |
| `FAVICON` | Путь к значку браузера или URL-адрес. |
| `TITLE_TEMPLATE` | заголовок страницы; `%s` заменяется заголовком страницы. |
| `PRODUCT_URL`, `DOCS_URL`, `REPOSITORY_URL` | Дополнительные навигационные ссылки. |

Публичная конфигурация отправляется в браузер. Никогда не храните пароли или токены в переменных `NUXT_PUBLIC_*`. См. [брендинг и тематика](/ru/docs/theming), чтобы узнать о вариантах цвета и оформления.

## Схема сети

Браузер взаимодействует с Crateview по одному источнику. Nitro проксирует `/v2/**` для клиентов реестра и считывает метаданные реестра через `/api/registry/**`. Это позволяет избежать необходимости доступа браузера из разных источников к самому реестру.

За обратным прокси-сервером сохраните общедоступный источник и заголовки протоколов. Адрес общедоступного внешнего интерфейса также является адресом реестра, отображаемым в скопированных командах pull. Для удаленного использования с аутентификацией правильно завершите HTTPS, прежде чем принимать учетные данные браузера или CLI.

## Compose по сравнению с автономной конфигурацией

Входящий в комплект файл Compose намеренно подключается к собственной службе `registry` с помощью `NUXT_REGISTRY_UPSTREAM=http://registry:5000`. Чтобы использовать другой реестр в развертывании контейнера, адаптируйте эту сервисную среду или запустите внешний интерфейс отдельно. Не предполагайте, что реестр хост-петли доступен через шлюз контейнера.
