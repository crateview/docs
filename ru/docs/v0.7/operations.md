## Включить удаление манифеста

Удаление отключено в пользовательском интерфейсе Crateview по умолчанию. И интерфейс, и Distribution должны это разрешать:

```dotenv
NUXT_REGISTRY_DELETE_ENABLED=true
```

```yaml
storage:
  delete:
    enabled: true
```

Distribution также может читать `REGISTRY_STORAGE_DELETE_ENABLED=true`. Перезапустите соответствующие службы после изменения их среды или конфигурации. Реестр продолжает отвечать за авторизацию, включая запросы, сделанные непосредственно через `/v2/**`.

## Общие сведения об удалении digest

Стандартная операция удаления нацелена на **манифест digest**. Каждый тег, указывающий на этот digest, можно удалить. Crateview просматривает затронутые теги перед подтверждением, но участник одновременной записи может изменить ссылки после предварительного просмотра: реестр API не предоставляет транзакцию, которая блокирует псевдонимы.

Рассматривайте удаление как изменение манифеста и всех его псевдонимов, а не как удаление одной метки. Перед подтверждением проверьте свои резервные копии и предполагаемую область действия.


Выберите один или несколько тегов таблицы и подтвердите удаление. Предпросмотр обновляет затронутые теги, одинаковые digest удаляются один раз, частичные ошибки сообщаются. Затрагиваются все псевдонимы. Сборка мусора остаётся отдельной задачей реестра.

## Сбор мусора и резервное копирование

Удаление манифеста не обещает немедленного восстановления диска. Сбор мусора — это отдельная задача администрирования реестра; Crateview его не запускает.

Создайте резервную копию хранилища реестра и его конфигурации, используя метод, соответствующий драйверу хранилища. Сохраняйте объемы при замене контейнеров. Следуйте инструкциям Distribution по сбору мусора и координации записи:

- [Distribution сбор мусора ](https://distribution.github.io/distribution/about/garbage-collection/)
- [Конфигурация Distribution](https://distribution.github.io/distribution/about/configuration/)

## Обновление Crateview

Просмотрите примечания к выпуску, установите для `CRATEVIEW_VERSION` желаемый тег выпуска с префиксом `v` в `.env` и замените интерфейсный контейнер:

```sh
docker compose pull frontend
docker compose up -d --no-deps frontend
```

Например, в первоначальной версии используется `CRATEVIEW_VERSION=v0.7.0`. Для отката восстановите предыдущий тег и повторите эти команды. Сохраните среду выполнения и том `registry-data`; не запускайте `docker compose down --volumes`. Исходные сборки остаются доступными через `compose.build.yaml`.

Dependabot настроен в исходном репозитории для предложения обновлений зависимостей; он не обновляет ваше локальное развертывание автоматически. Повторно проверьте подключение к реестру, вход в систему и затронутые действия после обновления.

## Большие реестры

Поиск по репозиторию считывает полный каталог с разбивкой на страницы. Метаданные для видимых репозиториев извлекаются по требованию. Сортировка большого списка тегов по времени создания образа может потребовать чтения множества манифестов и конфигураций. Crateview не имеет фонового индекса метаданных или внешней службы поиска.
