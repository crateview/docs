## Более четкое представление вашего реестра

Crateview — это веб-интерфейс для реестров контейнеров Docker и OCI. Он помогает вам находить репозитории и теги, проверять многоплатформенные изображения, читать манифесты и документы конфигурации, а также понимать сжатые слои и их историю.

Он работает вместе с вашим реестром. В реестре хранятся изображения и обеспечивается контроль доступа; Crateview предоставляет интерфейс и прокси того же происхождения. Docker и другие клиенты OCI могут использовать источник внешнего интерфейса в качестве адреса реестра.

![Обзор репозитория Crateview с Alpine и вложенными демонстрационными репозиториями.](https://crateview.de/images/docs/next/repositories-light.webp)

## Архитектура

```text
Browser / Docker / Podman / ORAS
              |
       Crateview (Nuxt / Nitro)
              |
   Your existing OCI registry
```

Каталог не требует БД; необязательный мониторинг использует постоянную SQLite. Аккаунты хранятся в htpasswd и отдельном файле прав.

## Поддерживаемые функции

- Поиск по имени репозитория, предложения тегов и вложенные пространства имен.
- Таблицы тегов, выбор платформы, размеры сжатых слоев и история изображений.
- OCI аннотации к описаниям, исходным URL-адресам, документации и лицензиям.
- Необработанный манифест и конфигурация JSON с поддержкой буфера обмена.
- Рефереры OCI, включая стандартный резервный индекс индекса digest, поддерживаемый клиентами OCI.
- Анонимный доступ и родной htpasswd Basic Auth.
- Необязательное удаление манифеста с отображением затронутых тегов перед подтверждением.
- 13 языков интерфейса, системный/светлый/темный и настраиваемый брендинг.

- Мониторинг необязателен и изначально выключен. При включении Обзор открывает панель, иначе /home перенаправляет на /explore. Включение раскрывает общие эксплуатационные данные всем пользователям UI, включая анонимных посетителей публичных реестров. Управляемый токенный режим дополнительно требует глобального права чтения.

## Знайте границы

Стандартный API не предоставляет временные метки push, статистику загрузок, избранное или сканирование уязвимостей. Crateview не выдумывает эти значения. Дата создания изображения берется из метаданных изображения и не является временем его загрузки. Отображаемые размеры описывают слои сжатого образа, а не использование диска реестра.

Администрирование объединяет Настройки и Пользователей. Меню аккаунта также содержит язык и тему. Аккаунт позволяет сменить свой пароль с подтверждением текущего. Серверный список разрешений управляет просмотром и созданием аккаунтов; права токенов доступны только для чтения. Новый пароль: минимум 12 символов и максимум 72 байта UTF-8. Новые токенные аккаунты изначально не имеют доступа к репозиториям.

Серверный список разрешений управляет просмотром, созданием, сбросом паролей и удалением учётных записей. Меню с тремя точками справа позволяет администраторам сбросить пароль другого пользователя без старого пароля или удалить его учётную запись после подтверждения. Сброс сохраняет права на репозитории; удаление убирает их. Собственное меню открывает раздел «Учётная запись» для смены пароля с текущим паролем; удаление своей учётной записи запрещено.
