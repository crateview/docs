## 更清晰地查看您的镜像仓库

Crateview 是 Docker 和 OCI 容器镜像仓库的 Web 界面。它可以帮助您查找存储库和标签、检查多平台映像、读取清单和配置文档以及了解压缩层及其历史记录。

它与您的镜像仓库一起运行。镜像仓库存储图像并强制执行访问控制； Crateview提供接口和同源代理。 Docker 和其他 OCI 客户端可以使用前端源作为其镜像仓库地址。

![Crateview 存储库概述，包含 Alpine 和嵌套演示存储库。](https://crateview.de/images/docs/v0.8/repositories-light.webp)

## 建筑学

```text
Browser / Docker / Podman / ORAS
              |
       Crateview (Nuxt / Nitro)
              |
   Your existing OCI registry
```

核心目录不需要数据库；可选监控使用持久化 SQLite。账户数据使用 htpasswd 和独立权限文件。

## 支持的功能

- 存储库名称搜索、标签建议和嵌套命名空间。
- 标签表、平台选择、压缩层大小和图像历史记录。
- OCI 说明、源 URL、文档和许可证的注释。
- 带有剪贴板支持的原始清单和配置 JSON。
- OCI 引荐来源网址，包括 OCI 客户端维护的标准 digest 标签索引回退。
- 匿名访问和本机 htpasswd Basic Auth。
- 可选的清单删除，并在确认之前显示受影响的标签。
- 13 种界面语言、系统/浅色/深色以及可配置的品牌。

- 监控可选，默认关闭。启用后概览显示仪表盘，否则 /home 重定向至 /explore。启用会向所有有界面访问权的用户开放整个注册表的运行数据，公共注册表也包括匿名访问者。托管令牌模式还要求全局读取权限。

## 知道界限

标准API不提供push时间戳、下载统计、收藏夹或漏洞扫描。 Crateview 不会伪造这些值。图像创建日期来自图像元数据，而不是其上传时间。显示的大小描述的是压缩图像层，而不是镜像仓库的磁盘使用情况。

管理区域包含设置和用户。账户菜单也提供语言和主题。账户页面要求当前密码才能修改自己的密码。只有服务器允许名单授权的用户才能列出和创建账户；令牌权限只读。新密码至少12个字符且最多72个UTF-8字节。新令牌账户最初无仓库访问权。

服务器允许列表控制账户查看、创建、密码重置和删除。 右侧三点菜单允许管理员在不提供旧密码的情况下重置其他用户的密码，或在确认后删除其账户。重置密码保留仓库权限；删除账户会移除权限。自己的菜单会打开“账户”，需要当前密码才能更改密码；不能删除自己的账户。
