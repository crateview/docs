## طبقات التكوين

تم تعريف الإعدادات الافتراضية للتطبيق في `nuxt.config.ts` و`app/app.config.ts`. تتجاوز متغيرات البيئة الإعدادات الافتراضية لوقت التشغيل عند بدء تشغيل الخادم. تقرأ أوامر التطوير والبناء `.env`؛ نقطة دخول عقدة الإنتاج لا تقرأها تلقائيًا.

أعد تشغيل الخادم بعد تغيير متغيرات بيئة التشغيل. يتطلب تحرير تكوين المكون على مستوى المصدر إنشاء إنتاج جديد.

## إعدادات التسجيل والجلسة

| عامل | تقصير | غاية |
| ------------------------------ | ----------------------- | ----------------------------------- |
| `NUXT_REGISTRY_UPSTREAM` | `http://127.0.0.1:5000` | أصل التسجيل من جانب الخادم. |
| `NUXT_REGISTRY_DELETE_ENABLED` | `false` | فضح حذف البيان في واجهة المستخدم. |
| `NUXT_SESSION_PASSWORD` | عشوائية لكل عملية | السر المستخدم لتشفير جلسات واجهة المستخدم. |
| `HOST` | تعتمد على وقت التشغيل | واجهة الاستماع لخادم العقدة. |
| `PORT` | `3000` | منفذ الاستماع لخادم العقدة. |

يجب أن يكون المنبع من أصل HTTP(S) يمكن الوصول إليه من خادم الواجهة الأمامية. احتفظ ببيانات الاعتماد خارج عنوان URL. تستخدم الطلبات مصادقة المستخدم الحالي؛ Crateview لا يحل محل التحكم في الوصول إلى التسجيل.

## متغيرات العلامة التجارية العامة

تستخدم جميع الأسماء أدناه البادئة `NUXT_PUBLIC_BRAND_`:

| لاحقة | غاية |
| ------------------------------------------- | ----------------------------------------------- |
| `NAME` | اسم التطبيق. |
| `DESCRIPTION` | وصف التطبيق. |
| `LOGO_LIGHT`، `LOGO_DARK` | مسارات الشعار أو عناوين URL لـ HTTP(S). |
| `FAVICON` | مسار رمز المتصفح أو عنوان URL. |
| `TITLE_TEMPLATE` | عنوان الصفحة؛ يتم استبدال `%s` بعنوان الصفحة. |
| `PRODUCT_URL`، `DOCS_URL`، `REPOSITORY_URL` | روابط التنقل الاختيارية. |

يتم إرسال التكوين العام إلى المتصفح. لا تقم مطلقًا بتخزين كلمات المرور أو الرموز المميزة في متغيرات `NUXT_PUBLIC_*`. راجع [العلامة التجارية والسمات](/ar/docs/v0.6/theming) للتعرف على خيارات الألوان والطباعة.

## تخطيط الشبكة

يتصل المتصفح بـ Crateview من أصل واحد. وكيل Nitro `/v2/**` لعملاء التسجيل ويقرأ بيانات تعريف التسجيل من خلال `/api/registry/**`. وهذا يتجنب طلب الوصول عبر المتصفح إلى السجل نفسه.

خلف الوكيل العكسي، احتفظ بالأصل العام ورؤوس البروتوكول. عنوان الواجهة الأمامية العامة هو أيضًا عنوان التسجيل المعروض في أوامر pull المنسوخة. للاستخدام المعتمد عن بعد، قم بإنهاء HTTPS بشكل صحيح قبل قبول بيانات اعتماد المتصفح أو واجهة سطر الأوامر (CLI).

## Compose مقابل التكوين المستقل

يتصل ملف Compose المُجمّع عمدًا بخدمة `registry` الخاصة به مع `NUXT_REGISTRY_UPSTREAM=http://registry:5000`. لاستخدام سجل آخر في نشر الحاوية، قم بتكييف بيئة الخدمة هذه أو قم بتشغيل الواجهة الأمامية بشكل منفصل. لا تفترض أن تسجيل استرجاع المضيف يمكن الوصول إليه من خلال بوابة الحاوية.
## إعدادات هذا الإصدار

المراقبة اختيارية ومعطلة افتراضياً. تفتح النظرة العامة لوحة المراقبة عند تفعيلها؛ وإلا يحوّل /home إلى /explore. يمنح التفعيل البيانات التشغيلية الشاملة لكل من يصل للواجهة، بما فيهم زوار السجلات العامة المجهولون. يتطلب وضع الرموز المُدار إذن قراءة عام أيضاً.

| ENV | Default |
| --- | --- |
| `NUXT_MONITORING_ENABLED` | `false` |
| `NUXT_MONITORING_METRICS_URL` | — |
| `NUXT_MONITORING_METRICS_TOKEN` | — |
| `NUXT_MONITORING_WEBHOOK_SECRET` | — |
| `NUXT_MONITORING_DATABASE_PATH` | `.dev/monitoring.sqlite` |

[المراقبة](/ar/docs/v0.6/monitoring)

| ENV | Default |
| --- | --- |
| `NUXT_AUTH_MODE` | `off` |
| `NUXT_AUTH_SERVICE_URL` | — |
| `NUXT_AUTH_SERVICE_SECRET` | — |
| `NUXT_AUTH_TOKEN_REALM` | — |
| `NUXT_USER_CREATION_ALLOWED_USERS` | — |

تجمع الإدارة الإعدادات والمستخدمين. توفر قائمة الحساب اللغة والمظهر أيضاً. يغيّر الحساب كلمة مرورك بعد التحقق من الحالية. تتحكم قائمة سماح الخادم في عرض الحسابات وإنشائها؛ صلاحيات الرموز للقراءة فقط. كلمات المرور الجديدة12 محرفاً على الأقل و72 بايت UTF-8 كحد أقصى. لا تملك حسابات الرموز الجديدة وصولاً أولياً للمستودعات.

تتحكم قائمة السماح على الخادم في عرض الحسابات وإنشائها وإعادة تعيين كلمات المرور وحذفها. تتيح قائمة النقاط الثلاث المحاذاة إلى اليمين للمسؤولين إعادة تعيين كلمة مرور مستخدم آخر دون كلمة المرور القديمة أو حذف حسابه بعد التأكيد. تحتفظ إعادة التعيين بصلاحيات المستودعات؛ ويحذف حذف الحساب تلك الصلاحيات. تفتح قائمتك الخاصة صفحة الحساب لتغيير كلمة المرور باستخدام الحالية؛ ولا يمكن حذف حسابك الخاص.

## إعداد أيقونات PWA

| المتغير | القيمة الافتراضية | الغرض |
| --- | --- | --- |
| `NUXT_PUBLIC_BRAND_PWA_ICON_192` | `/branding/pwa-192.png` | عنوان أيقونة التثبيت بحجم 192 بكسل. |
| `NUXT_PUBLIC_BRAND_PWA_ICON_512` | `/branding/pwa-512.png` | عنوان أيقونة التثبيت بحجم 512 بكسل. |
| `NUXT_BRAND_PWA_ICON_192_FILE` | — | ملف PNG خاص بحجم 192 بكسل له الأولوية. |
| `NUXT_BRAND_PWA_ICON_512_FILE` | — | ملف PNG خاص بحجم 512 بكسل له الأولوية. |

للملفات المحلية أولوية على العناوين العامة المقابلة. يجب أن تكون ملفات PNG قابلة للقراءة وغير فارغة وبالأبعاد المربعة المحددة تمامًا. تمنع الملفات غير الصالحة بدء الخادم. تُحل المسارات النسبية من مجلد عمل الخادم؛ ويجب أن تشير مسارات الحاوية إلى ملفات قابلة للقراءة داخلها. أعد التشغيل بعد التغييرات.

تراعي عناوين الأيقونات المحلية وملف البيان `NUXT_APP_BASE_URL` مثل `/registry/`؛ وتُحفظ عناوين HTTP(S) الخارجية كما هي. متغيرات الملفات الخاصة ليست لحفظ الأسرار: بيانات الصور عامة، بينما تبقى مسارات نظام الملفات على الخادم.
