## رؤية أوضح للسجل الخاص بك

Crateview عبارة عن واجهة ويب لسجلات الحاويات Docker وOCI. يساعدك في العثور على المستودعات والعلامات، وفحص الصور متعددة المنصات، وقراءة البيانات ومستندات التكوين، وفهم الطبقات المضغوطة وتاريخها.

يتم تشغيله بجانب السجل الخاص بك. يقوم السجل بتخزين الصور ويفرض التحكم في الوصول؛ يوفر Crateview الواجهة والوكيل من نفس المصدر. يمكن لـ Docker وعملاء OCI الآخرين استخدام أصل الواجهة الأمامية كعنوان التسجيل الخاص بهم.

![نظرة عامة على مستودع Crateview مع مستودعات Alpine التجريبية والمتداخلة.](https://crateview.de/images/docs/v0.6/repositories-light.webp)

## بنيان

```text
Browser / Docker / Podman / ORAS
              |
       Crateview (Nuxt / Nitro)
              |
   Your existing OCI registry
```

لا يحتاج الكتالوج قاعدة بيانات؛ تستخدم المراقبة الاختيارية SQLite دائماً. الحسابات في htpasswd وملف صلاحيات منفصل.

## الميزات المدعومة

- البحث عن اسم المستودع واقتراحات العلامات ومساحات الأسماء المتداخلة.
- جداول العلامات واختيار النظام الأساسي وأحجام الطبقات المضغوطة وتاريخ الصور.
- التعليقات التوضيحية OCI للأوصاف وعناوين URL المصدر والوثائق والتراخيص.
- البيان الخام وتكوين JSON مع دعم الحافظة.
- مُحيلات OCI، بما في ذلك معيار digest الاحتياطي لمؤشر العلامة الذي يحتفظ به عملاء OCI.
- الوصول المجهول وhtpasswd الأصلي Basic Auth.
- حذف البيان الاختياري، مع إظهار العلامات المتأثرة قبل التأكيد.
- 13 لغة واجهة، نظام/فاتح/داكن، وعلامة تجارية قابلة للتكوين.

- المراقبة اختيارية ومعطلة افتراضياً. تفتح النظرة العامة لوحة المراقبة عند تفعيلها؛ وإلا يحوّل /home إلى /explore. يمنح التفعيل البيانات التشغيلية الشاملة لكل من يصل للواجهة، بما فيهم زوار السجلات العامة المجهولون. يتطلب وضع الرموز المُدار إذن قراءة عام أيضاً.

## تعرف على الحدود

لا يوفر API القياسي طوابع زمنية push أو إحصائيات التنزيل أو المفضلة أو فحص الثغرات الأمنية. Crateview لا يقوم بتصنيع هذه القيم. يأتي تاريخ إنشاء الصورة من البيانات الوصفية للصورة وليس وقت تحميلها. تصف الأحجام المعروضة طبقات الصور المضغوطة، وليس استخدام قرص التسجيل.

تجمع الإدارة الإعدادات والمستخدمين. توفر قائمة الحساب اللغة والمظهر أيضاً. يغيّر الحساب كلمة مرورك بعد التحقق من الحالية. تتحكم قائمة سماح الخادم في عرض الحسابات وإنشائها؛ صلاحيات الرموز للقراءة فقط. كلمات المرور الجديدة12 محرفاً على الأقل و72 بايت UTF-8 كحد أقصى. لا تملك حسابات الرموز الجديدة وصولاً أولياً للمستودعات.

تتحكم قائمة السماح على الخادم في عرض الحسابات وإنشائها وإعادة تعيين كلمات المرور وحذفها. تتيح قائمة النقاط الثلاث المحاذاة إلى اليمين للمسؤولين إعادة تعيين كلمة مرور مستخدم آخر دون كلمة المرور القديمة أو حذف حسابه بعد التأكيد. تحتفظ إعادة التعيين بصلاحيات المستودعات؛ ويحذف حذف الحساب تلك الصلاحيات. تفتح قائمتك الخاصة صفحة الحساب لتغيير كلمة المرور باستخدام الحالية؛ ولا يمكن حذف حسابك الخاص.
